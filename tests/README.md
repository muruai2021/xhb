# 猩伙伴民宿官网 - 测试套件

本目录包含猩伙伴民宿官网项目的 API 测试用例。

## 测试文件

- `api.test.js` - API 集成测试套件

## 运行测试

### 前置条件

1. 确保服务器运行在端口 4000
2. 安装测试依赖：`npm install --save-dev jest supertest`

### 启动服务器

```bash
npm start
```

服务器将在 http://localhost:4000 启动。

### 运行测试

```bash
npm test
```

## 测试覆盖

### 1. AI 对话功能测试 (`/api/ai/chat`)

- 正常对话应返回成功响应
- 空消息应返回 400
- 缺少 message 字段应返回 400
- 超长消息（>1000字符）应返回 400
- 对话应记录到 chat_logs
- 关键词匹配触发对应回复
- 未匹配关键词返回默认回复

### 2. 知识库 API 测试

**获取文件列表 (`GET /api/knowledge/files`)**
- 应返回所有知识库文件列表
- 返回的文件应包含 known 文件
- 每个文件对象应包含 filename, tags, updatedAt

**获取文件内容 (`GET /api/knowledge/files/:filename`)**
- 获取 index.md 内容应成功
- 获取不存在的文件应返回 404
- 非 .md 文件应返回 404
- 应正确解析 front-matter 中的 tags
- 应正确解析 front-matter 中的 updatedAt

**保存文件内容 (`PUT /api/knowledge/files/:filename`)**
- 更新知识库文件应成功（需认证）
- 未授权请求应返回 401
- 无效 token 应返回 401
- 更新不存在的文件应返回 404
- 缺少 content 字段应返回 400

### 3. 聊天记录 API 测试 (`/api/chat-logs`)

- 应返回聊天记录
- 应支持分页参数
- items 应包含正确的字段

### 4. 管理员登录 API 测试 (`/api/admin/login`)

- 正确凭据应返回 token
- 错误密码应返回 401
- 不存在的账号应返回 401
- 缺少必填字段应返回 400

### 5. 规则引擎降级测试

- 无 API Key 时应使用规则引擎
- 匹配"位置"关键词应返回位置信息
- 匹配"户型"关键词应返回户型信息
- 匹配"价格"关键词应返回价格信息
- 匹配"预订"关键词应返回预订信息
- 匹配"联系"关键词应返回联系信息
- 匹配"特色"关键词应返回特色信息
- 未匹配任何关键词应返回默认回复
- 大小写不敏感匹配

### 6. 健康检查 API 测试 (`/health`)

- 应返回 ok 状态

### 7. 通用错误处理测试

- 不存在的 API 路径应返回 404

### 8. 响应格式一致性测试

- 所有成功响应应包含 success: true
- 错误响应应包含 success: false 和 message

### 9. 限流测试

- 1分钟内超过5次登录失败应被限流
