# 位置交通指引

我们的房源分布在长沙三大核心区域，均位于地铁步行10分钟以内的一线江景地段。

## 三大小区

### 保利国际广场
- 区域：天心区
- 地铁站：碧沙湖站（4号线）
- 地址：长沙天心区保利国际广场

### 建发养云
- 区域：开福区
- 地铁站：开福寺站（1号线）
- 地址：长沙开福区新河街道潘家坪路建发养云

### 北辰三角洲
- 区域：开福区
- 地铁站：北辰三角洲站（1号线）
- 地址：长沙开福区沅浦路28号北辰三角洲

## 交通时间参考

| 出发地 | 预计时间 |
|--------|----------|
| 长沙黄花机场 | 40-50分钟 |
| 长沙高铁南站 | 35-45分钟 |
| 长沙火车站 | 20-30分钟 |

## 周边配套

- 商圈：步行可达北辰荟购物中心
- 景区：紧邻橘子洲头、岳麓山
- 地铁：三大站点覆盖主要地铁线路
